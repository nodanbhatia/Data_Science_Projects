## 🌟 About This Repository

Welcome to my **Data Science Projects** repository.

This repository contains a collection of practical projects developed to apply **Data Science, Data Analysis, Machine Learning, Natural Language Processing, and AI** concepts to real-world problems.

Each project focuses on a different problem and follows a practical data science workflow:

```text
📂 Data
   ↓
🧹 Data Cleaning
   ↓
🔍 Exploratory Data Analysis
   ↓
⚙️ Feature Engineering
   ↓
🤖 Machine Learning / NLP
   ↓
📊 Visualization
   ↓
💡 Insights
   ↓
🚀 Application
```

## 📈 1. Stock Analysis

A financial data analysis project designed to analyze historical stock-market data and generate interactive visual insights.

### 🔥 Features

* Historical stock-price analysis
* Open, High, Low, Close analysis
* Trading-volume analysis
* Daily return calculation
* Interactive Plotly charts
* Candlestick visualization
* Time-period analysis
* Streamlit dashboard

### 🛠️ Technologies

`Python` `Pandas` `NumPy` `Plotly` `Streamlit`
